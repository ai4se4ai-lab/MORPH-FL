# Terminology
Use model-driven investigation for the implemented four-family state and executable transformations; reserve claims of effectiveness for measured evidence. M1–M4 are domain views, not metalevels. T1/T2 are extraction, T3 a query/projection, T4 proposal grounding, T5 model-to-model probe mapping, T6 assessment/update, and T7 model-to-view projection followed by JSON rendering. Hypothesis = candidate locations/mechanism/predictions/assumptions/evidence links. Observation = recorded permitted-check output with provenance, not causal conclusion. Assessment = hypothesis-relative verdict and explicit evidence scope. Dialogue = role history. Reset = clear dialogue, optionally prune pools, retain observations/cost. Valid round = accepted response reaching monitor; attempted round = ceiling-consuming loop iteration. Portfolio = <=k hypotheses per investigator scope. Evidence scope (source/static/causal predicate) differs from investigator scope (shared/role). Dependency neighborhood is never a sound slice. Patch proxy means changed production-Python source, not adjudicated root cause. Causal abstention concerns historical dynamic support, not calibrated confidence.

First use: plain observation/hypothesis/dialogue in Introduction; exact definitions in Background; round/portfolio semantics in Approach. Symbols: h/H hypothesis/live pool; E observations; A dialogues; Q physical cache; k portfolio cap; W window; g/r/d/c valid-round evidence gain/repetition/diversity/tokens; C0/C original/remaining budget. No confidence probability symbol.

# Stage A plan and scope

20 October 2026; branch paper/tse-manuscript-20261020. User instruction takes precedence over prompt.md's paper/ and split sections layout: docs/TSE/main.tex contains all manuscript content and docs/TSE/references.bib all references. Supporting audit documents live in support/. Existing dirty source, results and documentation are preserved. The method described is the current working tree, not automatically the code frozen in past runs.

Reconnaissance establishes the central claim: separating observations, interpretations and dialogue makes restart retention explicit and testable; the study tests whether that representation and reset policy justify their costs compared with a text summary. The implementation guarantee is record retention only. The synthesis interface, static scopes, null confidence and approximate analysis bound all causal claims. A synthetic Python configuration-handler example will be used because selecting a real trace without a complete verified provenance chain risks treating source evidence as runtime diagnosis.

Stage B independently searches primary literature without draft access and creates verified bibliography/comparison notes. Stage C drafts Sections 1–4, with only outlines elsewhere, using template IEEEtran class and packages. Stage D uses three isolated technical/novelty/clarity reviewers and records all concerns; revisions cannot create code capabilities or evidence. Stage E edits voice; Stage F independently assesses linear readability and revisits confusion. Stage G repeats fresh focused review and checks compile/citations/defaults/macros. Stop reviewer iteration at four rounds if major gaps remain and disclose them. Final review is advisory and honest, not an acceptance target to manufacture.

Research questions: patch-proxy ranking under equal budgets; component effects and conditional recovery after disclosed proxy-wrong leads; observed cost and static-evidence reliability. Dynamic causal validity and confidence calibration require evidence unavailable from the prospective source-only protocol and cannot be answered by these runs.

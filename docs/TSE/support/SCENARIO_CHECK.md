# Scenario checks
Positive: specification/audit contract and controlled-study contribution remain true; claims limited to measured proxy outcomes. Mixed: same contributions, report model/task/budget heterogeneity without superiority. Negative: same executable memory contract, simpler summary/no-reset controls may earn preference; retention never implies effectiveness.

Outcome-robust contributions: precise executable restart contract and non-guarantees; controlled experiment instrument including summaries/ablations/disclosed misdirection; replication package; findings only via claim slots. RQ1 compares proxy rankings under equal logical budgets. RQ2 tests eligible proxy recovery/component contrasts, not validated psychological fixation. RQ3 tests actual tokens/budget curves and descriptive evidence scope, excludes unavailable calibration/dynamic causal validity/dollars. Supported favorable differences -> conditional benefit; supported unfavorable differences -> disadvantage; mixed/uncertain -> no consistent advantage. Retention remains separate in all scenarios.

Post-review narrowing: favorable rankings permit only a package claim against configured controls, not superiority over prose summaries or typed-representation benefit. Mixed/negative results remain informative only if the completed study establishes useful conditions or repeatable failure mechanisms; no scenario guarantees TSE significance. Loss/suppression semantics are explicitly part of the prototype study. View sufficiency is unmeasured in every scenario. A merely correct ID-retention invariant plus null contrasts is not advertised as a sufficient journal contribution.
